SECTION 1: SOFTWARE TO INSTALL ON YOUR DEVICE (NOT npm)
================================================================================

These must be installed separately on your Windows PC:

  1. Node.js (LTS)
     Download : https://nodejs.org
     Purpose  : Runs the NestJS API server
     Includes : npm (package manager)

  2. Docker Desktop (RECOMMENDED)
     Download : https://www.docker.com/products/docker-desktop/
     Purpose  : Runs PostgreSQL + Redis in containers
     Command  : docker compose up -d postgres redis

     OR install manually:
       - PostgreSQL : https://www.postgresql.org/download/windows/
       - Redis      : https://www.memurai.com/  (Redis for Windows)

  3. Google Cloud Platform (OPTIONAL - for file uploads later)
     Purpose  : Google Cloud Storage (GCS) for documents/images
     Needs    : GCP project, bucket, service account JSON key file
     Config   : Set GCS_PROJECT_ID, GCS_BUCKET, GCS_KEY_FILE_PATH in .env

  4. Git (OPTIONAL but recommended)
     Download : https://git-scm.com/download/win
     Purpose  : Version control

SECTION 5: ENVIRONMENT VARIABLES (.env file)
================================================================================

  Copy .env.example to .env and configure:

  APP
  ---
  NODE_ENV=development
  PORT=3000
  API_PREFIX=api/v1
  APP_NAME=ERP Backend

  DATABASE (PostgreSQL)
  ---------------------
  DATABASE_URL=postgresql://erp:erp_secret@localhost:5432/erp_db?schema=public

  JWT (Authentication)
  --------------------
  JWT_SECRET=your-secret-key-min-32-characters
  JWT_ACCESS_EXPIRATION=15m
  JWT_REFRESH_EXPIRATION=7d

  REDIS
  -----
  REDIS_HOST=localhost
  REDIS_PORT=6379
  REDIS_PASSWORD=
  REDIS_DB=0

  BULLMQ
  ------
  BULLMQ_PREFIX=erp

  GOOGLE CLOUD STORAGE (optional for auth phase)
  ----------------------------------------------
  GCS_PROJECT_ID=your-gcp-project-id
  GCS_BUCKET=your-erp-bucket
  GCS_KEY_FILE_PATH=./gcp-service-account.json
  GCS_PUBLIC_BASE_URL=

SECTION 6: NPM SCRIPTS (commands you will use)
================================================================================

  npm install              Install all packages (run this first)
  npm run start:dev        Start API in development mode (hot reload)
  npm run start:prod       Start production build
  npm run build            Compile TypeScript to dist/
  npx prisma generate      Generate Prisma client after schema changes
  npx prisma migrate dev   Create/apply database migrations
  npm run prisma:seed      Seed permissions into database
  npx prisma studio        Open visual database browser
  npm run test             Run unit tests
  npm run lint             Run ESLint

SECTION 7: INSTALLATION STEPS (ORDER)
================================================================================

  Step 1 : Install Node.js LTS from https://nodejs.org
  Step 2 : Install Docker Desktop from https://www.docker.com/products/docker-desktop/
  Step 3 : Open terminal in project folder:
           cd C:\ERP-Backend
  Step 4 : Install npm packages:
           npm install
  Step 5 : Copy environment file:
           copy .env.example .env
  Step 6 : Start PostgreSQL + Redis:
           docker compose up -d postgres redis
  Step 7 : Setup database:
           npx prisma generate
           npx prisma migrate dev --name init
           npm run prisma:seed
  Step 8 : Start the server:
           npm run start:dev
  Step 9 : Open Swagger docs:
           http://localhost:3000/docs
