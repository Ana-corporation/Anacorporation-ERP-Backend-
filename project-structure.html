Overview — 4 main areas

Each folder has a single responsibility.

src/

NestJS application — APIs, services, guards, auth logic. TypeScript only. Runs with npm run start:dev.

sql/migrations/iam/

Database schema + validation — CREATE TABLE and CHECK constraints. Run against PostgreSQL separately.

prisma/

ORM schema (old design). Will be updated to match new IAM tables after migrations run.

scripts/

Helper commands — run migrations, list/drop tables, setup, JWT secret generator.
