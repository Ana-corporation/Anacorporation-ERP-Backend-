SETUP (one time)
----------------
  1. Install Bruno: https://www.usebruno.com/downloads
  2. Open Collection -> C:\ERP-Backend\bruno\ERP-Backend-Auth
  3. Environment (top-right): Local
  4. Bruno Settings -> Cookies -> ON
  5. Terminal:
       cd C:\ERP-Backend
       npx prisma migrate deploy
       npm run seed:erp-modules
       npm run seed:phase1-login
       npm run start:dev


EASIEST WAY TO TEST ALL (Collection Runner)
-------------------------------------------

  2. Right-click folder: 01-company-auth-flow -> Run
