1. HOW A PART NUMBER IS MADE
----------------------------
  ITEM number series: prefix ANA + category code + 5 digits, no separator.
  Each category has its own counter:  ANA + RM + 00001 = ANARM00001
  Old code (old_code) = the drawing / old part number from the BS500 sheet
  (e.g. BS5017000010). Shown as "Old ..." next to the part number.

4. WHAT IS MIXED UP
-------------------
4.1 FF numbers do not match the RM / SF numbers   <-- main problem
    SF follows RM exactly (264 of 264 match).
    FF does NOT: 227 of 238 differ, because the 26 sub-assembly parts get
    no FF, so the FF counter falls behind after the first one.

      RM          SF          FF
      ANARM00011  ANASF00011  ANAFF00011   match
      ANARM00012  ANASF00012  -            sub-assembly (no FF)
      ANARM00013  ANASF00013  -            sub-assembly (no FF)
      ANARM00014  ANASF00014  ANAFF00012   <- should be ANAFF00014
      ANARM00016  ANASF00016  ANAFF00013   <- should be ANAFF00016
      ...
      ANARM00264  ANASF00264  ANAFF00238   <- should be ANAFF00264

4.2 Same old code on 2-3 items
    RM, SF and FF of one part all carry the same old code
    (e.g. BS5018030020 on ANARM00012 and ANASF00012). 264 old codes are
    now shared. Searching by old code returns 2-3 items.

4.3 BS500 machine part number is ANAASSY00012 (ASSY category)
    Kept on purpose (you chose to keep it in Assemblies). It is hidden on
    machine screens and the Material master. Not wrong, just a note.
