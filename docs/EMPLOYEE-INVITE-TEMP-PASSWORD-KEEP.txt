3) Invite still returns temporaryPassword
   Existing FE body still works:
     { firstName, lastName, email, mobile, employeeId, roleId, sendInviteEmail }

   Optional new fields (backward compatible):
     personType: "EMPLOYEE" | "EXTERNAL"
     employeeRecordId: "<employees.employee_id>"

   Behaviour:
     - EXTERNAL (default when no employeeId/employeeRecordId)
         → no employees row
     - EMPLOYEE / employeeId present
         → create or link employees row + set employees.user_id
     - employeeRecordId present
         → link that existing Employee to the invited User
         → sync membership.employeeId from employee.employeeCode

   sendInviteEmail = true still only stubs a log (no SMTP).
