1) HOW BAGS WORK
--------------------------------------------------------------------------------

  Request field     → DB column
  ----------------    -------------------
  purchase          → purchase_json
  sales             → sales_json
  inventory         → inventory_json
  planning          → planning_json
  production        → production_json
  properties        → properties_json
  attachments       → attachments_json
  metadata          → metadata

  DTO validation:
    z.record(z.string(), z.unknown()).optional()
    → NO allow-list → unknown keys are NOT stripped

  Response echoes Prisma fields as camelCase:
    purchaseJson, salesJson, inventoryJson, planningJson,
    productionJson, propertiesJson, attachmentsJson, metadata

4) ALL ITEM MASTER APIs (current)
--------------------------------------------------------------------------------

  Base: /api/v1/companies/:companyId/items
  Guard: assertCompanyAccess + supply-chain module permission

  GET    /companies/:companyId/items
         List (pagination/filters)
         Permission: supply-chain view

  GET    /companies/:companyId/items/:id
         Get one + warehouseStock[]
         Warehouse rows filtered by Data Access Policy when user is restricted
         Permission: supply-chain view

  POST   /companies/:companyId/items
         Create (header columns + JSON bags)
         Permission: supply-chain create

  PATCH  /companies/:companyId/items/:id
         Update (partial). JSON bags shallow-merged.
         Permission: supply-chain edit

  DELETE /companies/:companyId/items/:id
         Soft delete
         Permission: supply-chain delete

  POST   /companies/:companyId/items/:id/attachments
         Multipart upload (files|file). Max 10MB. Returns fileAsset metadata.
         Permission: supply-chain edit
         See docs/FE-MATCH-ITEM-ATTACHMENTS.txt

  GET    /companies/:companyId/items/:id/attachments/:fileAssetId/url
         Signed download URL
         Permission: supply-chain view

  DELETE /companies/:companyId/items/:id/attachments/:fileAssetId
         Delete uploaded file from storage + soft-delete file_assets row
         Permission: supply-chain edit

  PUT    /companies/:companyId/items/:id/warehouses
         Upsert warehouse stock row (scope-checked)
         Permission: supply-chain edit
         Out-of-scope warehouse → 403

  DELETE /companies/:companyId/items/:id/warehouses/:warehouseId
         Remove warehouse stock row (scope-checked)
         Permission: supply-chain delete
