WHAT FE SAW
--------------------------------------------------------------------------------

  Symptom:
    Settings → Form Configuration → Vendor Configure
    Page loads but API returns 403 "Insufficient permissions"

  Login (ADMIN001):
    tenantAdmin: true
    permissions[] had custom_fields:* but NOT form_configurations:*

  Affected call:
    GET /api/v1/companies/{companyId}/form-configurations/vendor → 403

  FE behavior was correct:
    - Nav + route wired properly
    - API path correct
    - Permission gates correct (can("form_configurations:view"))


ROOT CAUSE (BE — not an FE bug)
--------------------------------------------------------------------------------

  Backend ADMIN role in DEMO_ACME was seeded before form_configurations:*
  permissions existed. Login backfill did not grant the new codes to existing
  ADMIN roles.

  FE nav may show Form Configuration via tenantAdmin (temporary UX).
  API guards require explicit permissions[] — hence 403 until BE fix + re-login.


BE FIX (already in backend)
--------------------------------------------------------------------------------

  On POST /auth/login (and /auth/me), backend now:
    1. Upserts missing permission catalog rows (including form_configurations:*)
    2. Backfills COMPANY_ADMIN role (roleCode ADMIN) with:
         form_configurations:view
         form_configurations:edit
         custom_fields:* (if missing)
         Security Org V1 codes (if missing)

  Seed script also assigns these to ADMIN001:
    npm run seed:client-logins


WHAT FE MUST DO
--------------------------------------------------------------------------------

  1. No code changes required for the 403 itself.

  2. After BE deploy / restart:
       - Logout ADMIN001 completely (clear token / session)
       - Login again: DEMO_ACME / ADMIN001 / Admin@123

  3. Confirm login response permissions[] includes:
       "form_configurations:view"
       "form_configurations:edit"

  4. Re-test Vendor Form Configuration page → GET should return 200.

--------------------------------------------------------------------------------

  | Code                        | FE usage                                      |
  |-----------------------------|-----------------------------------------------|
  | form_configurations:view    | Show Settings nav + read config (GET)         |
