WHY YOU SEE THESE ERRORS
------------------------
After git pull, TypeScript may fail with:

  1) Cannot find module '@nestjs/terminus'
  2) 'supplierType' does not exist on Vendor create / vendor object

These are NOT application bugs.
They mean the local machine is missing:

  - npm dependencies (node_modules)
  - regenerated Prisma Client (from updated prisma schema)

The pushed code already includes:
  - @nestjs/terminus in package.json
  - supplierType in prisma/purchase/vendors.prisma
  - migration: prisma/migrations/20260806120000_vendor_supplier_type/


FIX (RUN THESE IN ORDER)
------------------------
From the repo root (ERP-Backend):

  1. Pull latest code
       git pull

  2. Install dependencies
       npm install

     → Fixes: Cannot find module '@nestjs/terminus'

  3. Regenerate Prisma Client
       npx prisma generate

     → Fixes: supplierType does not exist on Vendor types

  4. Apply DB migration (needed for runtime / create vendor)
       npx prisma migrate deploy

     → Adds vendors.supplier_type column in the database

  5. Restart the app
       npm run start:dev


OPTIONAL / IF STILL FAILING
---------------------------

     Remove-Item -Recurse -Force node_modules

     npm run start:dev
