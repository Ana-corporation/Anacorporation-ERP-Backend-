    users:edit

      "departmentId": "12",
      "designationId": "3",
      "branchId": "1",

    }
    Org IDs must belong to this company (else 400).

P1 — STATUS
-----------
  PATCH /api/v1/companies/:companyId/users/:userId/status
    users:edit
    Body: { "status": "active" | "suspended" }
    Updates user_companies.status only (not users.isActive).
    "left" is not accepted (use DELETE).
    Returns list-item.


P2 — MODULE ACCESS ALIAS
------------------------
  PUT /api/v1/companies/:companyId/users/:userId/module-access
    user_module_access:edit
    Body:
    {
      "items": [
        { "moduleId": "5", "accessType": "grant" },
        { "moduleId": "8", "accessType": "deny" }
      ]
    }
    items = full override set.
    grant/deny = upsert override.
    Omitted modules = inherit role (existing override deleted).
    { "items": [] } clears all overrides.
    Returns list-item.
