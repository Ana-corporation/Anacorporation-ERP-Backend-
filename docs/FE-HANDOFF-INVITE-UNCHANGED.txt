================================================================================

  POST   /api/v1/companies/:companyId/users/invite
         Permission: users:create

  Request body (same as today — still valid):
  {
    "firstName": "Tom",
    "lastName": "Ben",
    "email": "tom@gmail.com",
    "mobile": "7576877657",
    "employeeId": "0095",
    "roleId": "42",
    "sendInviteEmail": true
  }

  Success response (same shape):
  {
    "success": true,
    "data": {
      "user": {
        "userId": "...",
        "username": "...",
        "displayName": "Tom Ben",
        "firstName": "Tom",
        "lastName": "Ben",
        "email": "tom@gmail.com",
        "mobile": "...",
        "isActive": true,
        "membership": {
          "userCompanyId": "...",
          "employeeId": "0095",
          "departmentId": null,
          "designationId": null,
          "branchId": null,
          "warehouseId": null,
          "status": "active",
          "isDefault": true
        },
        "role": {
          "roleId": "42",
          "roleCode": "...",
          "roleName": "..."
        }
      },
      "temporaryPassword": "Ab12xyZ!"
    }
  }

  Rules FE already relies on (still true):
    - New user  → temporaryPassword = string
    - Existing user added to company → temporaryPassword = null
    - roleId optional (null/omit = no role yet)
    - roleId may be string OR number (BE coerces)
    - sendInviteEmail does NOT send real email yet (BE stub only)


  GET    /api/v1/companies/:companyId/users?page=1&limit=100
         Permission: users:view
         Item shape STILL: { userId, membership, role, ... }


  PATCH  /api/v1/companies/:companyId/users/:userId
         users:edit   { firstName, lastName, mobile }
         Returns list-item shape


  PUT    /api/v1/companies/:companyId/users/:userId/role
         roles:edit   { "roleId": "42" }  or null to clear
         Returns list-item shape


  PATCH  /api/v1/companies/:companyId/users/:userId/membership
         users:edit
         { employeeId, departmentId, designationId, branchId, warehouseId }


  PATCH  /api/v1/companies/:companyId/users/:userId/status
         users:edit   { "status": "active" | "suspended" }


  DELETE /api/v1/companies/:companyId/users/:userId
         users:delete


  Auth (unchanged):
    POST /api/v1/auth/login
    GET  /api/v1/auth/me          → mustChangePassword
    POST /api/v1/auth/change-password
