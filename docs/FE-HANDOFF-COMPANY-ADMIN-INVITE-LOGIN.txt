  200 data:

    - Sessions/refresh tokens cleared
    - If employeeId was null, BE assigns ADMIN001 / ADMIN002 / ...
    - Email still STUBBED (no mail sent). Always show temporaryPassword in UI.

  Legacy alias (same behavior, same perm):
    POST /api/v1/companies/{companyId}/users/{userId}/reissue-temp-password
