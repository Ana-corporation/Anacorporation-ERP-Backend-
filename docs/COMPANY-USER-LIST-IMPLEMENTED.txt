WHAT CHANGED
------------
Same endpoint. New item shape = invite `data.user`.

  GET /api/v1/companies/:companyId/users?page=1&limit=100
  Permission: users:view

Each item now includes:
  userId, username, displayName, firstName, lastName, email, mobile, isActive
  membership { userCompanyId, employeeId, departmentId, designationId,
               branchId, warehouseId, status, isDefault }
  role      { roleId, roleCode, roleName }  or null

IDs are strings. Paginated wrapper unchanged:
  { items, total, page, limit, totalPages }
