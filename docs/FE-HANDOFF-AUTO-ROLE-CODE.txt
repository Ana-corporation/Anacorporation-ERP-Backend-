CREATE
--------------------------------------------------------------------------------

  POST /companies/{companyId}/roles

  Preferred body:

    {
      "roleName": "Purchase Approver",
      "description": "optional"
    }

  Also OK:

    {
      "roleCode": "PURCHASE_APPROVER",
      "roleName": "Purchase Approver"
    }

  Response always includes final roleCode, e.g.:

    {
      "roleId": "…",
      "roleCode": "PURCHASE_APPROVER",
      "roleName": "Purchase Approver",
      "roleType": "CUSTOM",
      "status": "ACTIVE"
    }


GENERATION RULES
--------------------------------------------------------------------------------

  From roleName "Purchase Approver":
    → PURCHASE_APPROVER

  If taken:
    → PURCHASE_APPROVER_2, _3, …

  Empty normalize fallback: ROLE
  Max length: 40 (DB VarChar(40))
  Charset: A-Z, 0-9, underscore


ERRORS
--------------------------------------------------------------------------------

  Duplicate explicit code:
    Conflict + code ROLE_CODE_EXISTS
    "Role code already exists in this company"

  Reserved system code (ADMIN, MANAGER, STAFF, …):
    400 + code ROLE_CODE_RESERVED
    "Role code ADMIN is reserved"

  Missing roleName:
    400 validation


CLONE
--------------------------------------------------------------------------------

  POST /companies/{companyId}/roles/{roleId}/clone

  roleCode optional — same rules as create.
  If omitted, generated from clone roleName (unique).
