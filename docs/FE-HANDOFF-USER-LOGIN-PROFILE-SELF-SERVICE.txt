2) SELF PROFILE APIs
================================================================================

  Scope: ALWAYS the JWT user + active company. Never send another userId.

  ------------------------------------------------------------------------------
  GET /users/me
  ------------------------------------------------------------------------------

    200

    {
      "user": { ...same as /auth/me user... },
      "membership": { ...same as activeCompany.membership... } | null,
      "role": { ...same as activeCompany.role... } | null
    }

    FE may call this instead of parsing the full /auth/me workspace snapshot.
    Allowed while mustChangePassword=true (same as GET /auth/me).

  ------------------------------------------------------------------------------
  PATCH /users/me
  ------------------------------------------------------------------------------

    Body — ONLY these keys:

      {
        "displayName": "Mohana Priya",
        "phone": "+91xxxxxxxxxx"
      }

    Send one or both. Empty phone string clears it (null).

    200  same payload as GET /users/me (updated)

    REJECTED if body contains:
      email, employeeCode, employeeId, roleId, departmentId, designationId,
      warehouseId, status, companyId, permissions, password

      → 422  "These fields cannot be changed on your profile"
      extra unknown keys → 400 (strict body)

    Admin changes those via existing:

      PATCH /companies/{companyId}/users/{userId}
      PUT   /companies/{companyId}/users/{userId}/role
      PATCH /companies/{companyId}/users/{userId}/membership   (dept / designation / warehouse)

  ------------------------------------------------------------------------------
  POST /users/me/avatar
  ------------------------------------------------------------------------------

    multipart/form-data
    field name: file   (required)

    Allowed: image/jpeg, image/png, image/webp
    Max:     2 MB
    Rejected: svg, exe, html, js, other types

    200  { "avatarUrl": "https://..." }

    Next GET /auth/me or GET /users/me includes the same avatarUrl on user.

  ------------------------------------------------------------------------------
  PATCH /users/me/settings   (optional — personal prefs only)
  ------------------------------------------------------------------------------

    {
      "locale": "en-IN",
      "dateFormat": "DD/MM/YYYY"
    }

    Send one or both.
    200  { "locale": "en-IN", "dateFormat": "DD/MM/YYYY" }

    Not company modules. Not other users' prefs.
