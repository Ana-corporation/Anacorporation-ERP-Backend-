TYPING LAG / PAGE JUMP (Serial No + Brand) — FIX ON FE
--------------------------------------------------------------------------------
  Symptom: type in Serial / Brand → long delay before char shows; page “moves”.
  Cause: Electrical draft has ~374 lines. If each keystroke:
    - updates global document state → re-renders whole grid / partIndex, OR
    - autosaves PUT with full lines[] → BE re-resolves all lines → lag
  then typing feels broken. BE is fine; PUT is whole-document replace.

  Required FE pattern:
  1) Local input state while focused (value updates instantly in the field)
  2) Do NOT PUT on every keypress
  3) Commit on blur OR debounce autosave ≥ 500–800 ms after last key
  4) After save, merge response carefully — do not wipe the focused input
     mid-type (ignore stale response if user is still typing that cell)
  5) Fixed column widths for Serial / Brand so layout does not jump
  6) Prefer editing only the expanded part’s lines in the UI tree
     (still send full lines[] on save, but don’t remount the whole page)

  Optional later BE: PATCH single-line endpoint (not in Phase 1).
