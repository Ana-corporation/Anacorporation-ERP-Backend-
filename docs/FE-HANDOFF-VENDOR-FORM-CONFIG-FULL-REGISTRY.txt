STATUS
--------------------------------------------------------------------------------

  BE vendor built-in registry now returns EVERY Vendor form field below
  as source = BUILT_IN. Form Configuration should list them after BE deploy.

  No FE code change required for listing — render all BUILT_IN rows from GET.
  Use fieldKey (not labels). FE alias map still works for older keys.

  NOT in this registry (by design):
    - countryCode / dialCode          (FE PhoneInput UI only)
    - Address Line 1/2/3, State name  (Custom Fields)
    - Attachments tab                 (file panel, not a form field)


SECTIONS (GET sections[].sectionKey)
--------------------------------------------------------------------------------

  general      General
  contact      Contact Details
  address      Address
  payment      Payment Terms
  bank         Business Partner Bank     (NEW grouping)
  paymentRun   Payment Run
  accounting   Accounting
  remarks      Remarks

  Visibility uses fieldKey, not section title.
  If a company hid a field, GET still returns the row with visible:false.


ALIASES (PUT accepts these; GET returns the canonical fieldKey only)
--------------------------------------------------------------------------------

  taxId, tax_id          → federalTaxId
  discountPercent        → totalDiscount
  iban                   → bankIban
  swift                  → bankSwift
  vendorCode             → supplierCode
  supplierType           → vendorCategory
