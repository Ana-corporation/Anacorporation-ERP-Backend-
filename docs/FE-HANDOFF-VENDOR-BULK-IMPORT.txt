APIs (all under /api/v1) — FE ALIGNED / BE CONFIRMED
--------------------------------------------------------------------------------

  1) Download template
     GET /companies/{companyId}/vendors/import/template
     Perm: vendors:create
     Response: Excel file download (.xlsx)

  2) Validate upload
     POST /companies/{companyId}/vendors/import/validate
     Content-Type: multipart/form-data
     Field name: file  (.xlsx or .csv, max 10 MB, max 5,000 rows)
     Perm: vendors:create

  3) Confirm import
     POST /companies/{companyId}/vendors/import/confirm
     Body: { "importId": "42" }   ← importId ONLY, never rows[]
     Perm: vendors:create

  4) Get session
     GET /companies/{companyId}/vendors/import/{importId}
     Perm: vendors:create
