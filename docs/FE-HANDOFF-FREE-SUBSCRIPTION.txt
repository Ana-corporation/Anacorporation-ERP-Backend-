SEED (BE / ops)
--------------------------------------------------------------------------------

  npm run seed:subscription-plans

  Creates/updates:
    FREE, STARTER, PROFESSIONAL, ENTERPRISE

  FREE:
    planCode:     FREE
    name:         Free
    price:        0
    billingCycle: monthly   ← DB enum has no "none"/"free"; monthly is fine
    maxUsers:     null (unlimited)
    modules:      every active product module in catalogue

  Note: seed promotes DEVELOPMENT/TESTING/INTERNAL product modules to
  AVAILABLE so the entitlement catalogue can surface them for FREE.


ASSIGN TO COMPANY (Platform Owner)
--------------------------------------------------------------------------------

  POST /companies/{companyId}/subscriptions

  Body:

    {
      "planId": "<FREE planId from GET /subscription/plans>",
      "startDate": "2026-09-08",
      "status": "active"
    }

  Optional fields may be omitted. BE applies for FREE / price=0:

    amount      = 0
    status      = active   (even if FE sends pending / omits status)
    endDate     = null     (forever — only when planCode=FREE)
    autoRenew   = false    (default for FREE; FE may override)

  No payment gateway / invoice call exists or is invoked.


LIST PLANS
--------------------------------------------------------------------------------

  GET /subscription/plans

  Each plan row now includes derived fields (no new DB columns):

    {
      "planId": "...",
      "planCode": "FREE",
      "name": "Free",
      "price": "0",
      "billingCycle": "monthly",
      "isActive": true,
      "isFree": true,
      "requiresPayment": false
    }

  PO UI: hide payment step when isFree === true OR requiresPayment === false.


LOGIN / ME / ENTITLEMENTS (NO FE SPECIAL CASE)
--------------------------------------------------------------------------------

  Use existing snapshot:

    activeCompany.subscription.planCode  = "FREE"
    activeCompany.subscription.status    = "active"
    activeCompany.subscription.isValid   = true
    activeCompany.subscription.endDate   = null

  modules[] come from entitlement engine:
    plan modules − REVOKE + GRANT, with company enable/disable

  Do NOT hardcode "show all modules" on FE.
  FREE is just another plan with a full plan_modules set.


CURRENT SUBSCRIPTION HELPER
--------------------------------------------------------------------------------

  GET /companies/{companyId}/subscriptions/current

  Returns (among other fields):

    planCode, status, isValid: true,
    plan: { code, name, planId, price, isFree, requiresPayment },
    endDate: null


UPGRADE LATER
--------------------------------------------------------------------------------

  Assign a paid plan via the same POST subscriptions endpoint.
  Previous live sub is expired; entitlements recompute from new plan.
