1) APIs (live)
--------------------------------------------------------------------------------

  POST   /api/v1/companies/:companyId/items/:itemId/attachments
         multipart/form-data
         fields: files (repeatable) and/or file
         Permission: supply-chain edit
         Max 10 MB / file
         Allowed: pdf, doc, docx, xls, xlsx, csv, jpg, jpeg, png, webp

  Response data:
  {
    "attachments": [
      {
        "fileAssetId": "uuid",
        "fileName": "datasheet.pdf",
        "mimeType": "application/pdf",
        "fileSize": 123456,
        "storageKey": "...",
        "publicUrl": "..." | null,
        "attachmentDate": "YYYY-MM-DD",
        "status": "uploaded"
      }
    ]
  }

  DELETE /api/v1/companies/:companyId/items/:itemId/attachments/:fileAssetId
         Permission: supply-chain edit
         → { success: true, message: "Attachment deleted", data: null }

  GET    /api/v1/companies/:companyId/items/:itemId/attachments/:fileAssetId/url
         Permission: supply-chain view
         → { url: "<signed>" }
