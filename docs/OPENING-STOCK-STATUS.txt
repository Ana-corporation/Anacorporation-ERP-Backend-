1. HOW OPENING STOCK WORKS NOW
------------------------------
  Save Draft  -> OS-000001 number, no stock change, editable
  Post        -> stock balance + stock ledger updated in ONE transaction, document locked
  Corrections -> Stock Adjustment (no reversal yet)
  Two ways in -> New Opening Stock screen, or Excel import (preview -> approve)


2. BUILT (backend, tested)
--------------------------
  Header
    - Document no. auto on save, Opening Stock Date, Remarks
    - Default Store (fills every line; each line keeps its own store)
    - Attachments (count sheets): upload draft/posted, delete draft only
    - Created / Edited / Posted by + on; "Imported from <file>" with approver
  Lines
    - Part no. from Item Master; Part Name, UOM, Item Type (RM/SF/FF/BRG...) read-only
    - Qty > 0; Unit Price; Line Total = Qty x Price (backend calculates)
    - Zero / blank price -> must tick "zero value confirmed", else posting refused
    - Batch / Heat / Lot No., Serial No., Revision, Line Remarks (reference text)
    - Store + Bin; bin required only for bin-managed stores (re-checked on post)
  Footer
    - Total Lines, Total Quantity, Total Stock Value (backend recalculates)
  Rules (backend, cannot be bypassed by API)
    - Duplicate line in one document blocked (item + store + bin + batch + serial)
    - Second opening stock for the same item + store + bin blocked
    - Material Issue / Stock Adjustment dated before the opening date blocked
    - Stock never negative; concurrent posting safe (row locks); retry posts once
  Excel import
    - Template with Instructions sheet; Location Code = store only, Bin column
    - Preview: Matched / New Item / Error; nothing saved before Approve
    - Category Code must match the item; error file with row, column, reason, suggestion
    - New items only after confirmation and only in allowed categories (SF/FF never)
    - Zero-price rows need confirmation; rows can be excluded
  Vendor (sub-contractor) stock
    - A store location can be linked to a vendor; inactive vendor blocked
    - Current Stock shows "At vendor" and filters by vendor
  Item Master (part numbers)
    - Category Stage RM / SF / FF
    - New RM item: "RM only" / "RM -> SF" (sub-assembly) / "RM -> SF -> FF" (main)
      creates the linked part numbers in one save; button to add missing SF/FF later
