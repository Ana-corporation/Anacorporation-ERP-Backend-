3. NEW / UPDATED APIs
--------------------------------------------------------------------------------

A) Meta (admin Create form dropdowns)
  GET /api/v1/custom-fields/meta/modules
  GET /api/v1/custom-fields/meta/modules/vendor/sections
      → sections[] + reservedFieldNames[]

B) Create (fieldName optional)
  POST /api/v1/companies/{companyId}/custom-fields
  {
    "entityType": "vendor",
    "sectionKey": "general",
    "displayName": "Factory Capacity",
    "fieldType": "number",
    "isRequired": false,
    "sortOrder": 40,
    "isFilterable": true,
    "validation": { "min": 0, "max": 100000 },
    "helpText": "Max units per day"
  }
  → generates fieldName "factoryCapacity"

C) List
  GET .../custom-fields?entityType=vendor
  GET .../custom-fields?entityType=vendor&groupedBySection=true

D) Form schema (Vendor form)
  GET .../entities/vendor/form-schema
  fields[] include: sectionKey, isFilterable, placeholder, helpText, …

E) Vendor list
  GET .../vendors?includeCustomFields=true
  GET .../vendors?cf.vendorTier=preferred
      (only if definition.isFilterable=true)
