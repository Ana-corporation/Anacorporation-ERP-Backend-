1) PROBLEM
--------------------------------------------------------------------------------

  src/hooks/use-auto-refresh.ts reloads the page data:
    - every 10 s (default) while the tab is visible
    - every time the window gets focus (also when clicking DevTools and back)

  21 screens use it. One open tab = ~360 API calls / hour on a 10 s screen.
  Every call hits Cloud Run + Cloud SQL (load, slowness, data transfer).

  Note: this fix cuts load, not the fixed cloud cost. The bill is mainly the backend
  Cloud Run setup (always-on instance) + Cloud SQL running 24/7 — fixed separately on BE.

  It is the ONLY automatic repeated call in the FE (checked: no other setInterval,
  no SWR / React Query, no WebSocket; /auth/refresh only runs on a 401).


2) NEW RULE
--------------------------------------------------------------------------------

  Load data when:
    a) the page opens                                   (already done)
    b) after a save / delete                            (requestDataRefresh())
    c) the user clicks a Refresh button                 (new, on lists)
    d) the tab comes back after being away >= 60 s      (throttled focus)

  No timer polling by default.


3) CHANGE THE HOOK  (src/hooks/use-auto-refresh.ts)
--------------------------------------------------------------------------------

  - intervalMs default 0 = no polling. Only poll when a screen passes intervalMs > 0.
  - Focus / visibility refresh only if the last load was >= 60 s ago.
  - DATA_REFRESH_EVENT and FORM_SCHEMA_INVALIDATE_EVENT still refresh at once.
  - Still skip while the tab is hidden.

  Sketch:

    export type AutoRefreshOptions = {
      /** Poll interval in ms. 0 / omitted = no polling. */
      intervalMs?: number;
      /** Min gap before a focus / tab-visible refresh. Default 60000. */
      focusMinGapMs?: number;
      enabled?: boolean;
    };

    export function useAutoRefresh(refresh, options: AutoRefreshOptions = {}) {
      const { intervalMs = 0, focusMinGapMs = 60_000, enabled = true } = options;
      const refreshRef = useRef(refresh);
      refreshRef.current = refresh;

      useEffect(() => {
        if (!enabled) return undefined;
        let cancelled = false;
        let inFlight = false;
        let lastRun = Date.now();                  // page just loaded its data

        const run = async (force: boolean) => {
          if (cancelled || inFlight || document.visibilityState === 'hidden') return;
          if (!force && Date.now() - lastRun < focusMinGapMs) return;
          inFlight = true;
          lastRun = Date.now();
          try { await refreshRef.current(); } finally { inFlight = false; }
        };

        const onFocus = () => void run(false);
        const onSaved = () => void run(true);
        const id = intervalMs > 0 ? window.setInterval(() => void run(true), intervalMs) : undefined;

        window.addEventListener('focus', onFocus);
        document.addEventListener('visibilitychange', onFocus);
        window.addEventListener(DATA_REFRESH_EVENT, onSaved);
        window.addEventListener(FORM_SCHEMA_INVALIDATE_EVENT, onSaved);
        return () => {
          cancelled = true;
          if (id) window.clearInterval(id);
          window.removeEventListener('focus', onFocus);
          document.removeEventListener('visibilitychange', onFocus);
          window.removeEventListener(DATA_REFRESH_EVENT, onSaved);
          window.removeEventListener(FORM_SCHEMA_INVALIDATE_EVENT, onSaved);
        };
      }, [enabled, intervalMs, focusMinGapMs]);
    }
