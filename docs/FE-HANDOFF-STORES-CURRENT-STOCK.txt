WHAT THE USER WANTS
--------------------------------------------------------------------------------
  Inventory → Setup → Stores: clicking a store opens the list of materials
  (on-hand qty) for that store / location — not bins, not edit.


WHAT WAS WRONG
--------------------------------------------------------------------------------
  Stores row click did nothing.
  The only “view” action was Manage bins (when Bin Mgmt = Yes).
  Current Stock could filter by location in the page dropdown, but had no
  URL deep-link from Stores.


BE (already exists — no change required for this)
--------------------------------------------------------------------------------
  GET /api/v1/companies/{companyId}/inventory/stock
  Query: inventoryLocationId  (alias: warehouseId)
         + search, siteId, storeCategoryId, storageBinId, vendorId,
           includeZero, sortBy, sortOrder, page, limit
  Permission: inventory_stock:view

  Returns Current Stock rows for that location (empty [] if nothing posted).


FE ROUTES
--------------------------------------------------------------------------------
  Stores list:     /dashboard/inventory/locations
  Current Stock:   /dashboard/inventory/current-stock?location={warehouseId}

  Path helper:
    paths.dashboard.inventory.currentStockAtLocation(warehouseId)


FE BEHAVIOUR (implemented)
--------------------------------------------------------------------------------
  Stores (LocationsPanel — inventory-setup-view.tsx)
    - Click row → navigate to currentStockAtLocation(warehouse_id)
    - Actions: box icon “Materials in this store” (same link)
    - Edit / delete / manage bins: stopPropagation (do not open stock)

  Current Stock (current-stock-view.tsx)
    - Reads ?location= on load / when URL changes
    - Sets Store filter = that inventoryLocationId
    - Calls listCurrentStock({ inventoryLocationId: location })
    - Page wrapped in Suspense (useSearchParams)
