ROOT CAUSE (FE — not a BE API bug)
--------------------------------------------------------------------------------
  1) Wrong API target (was the main issue)
       .env.local had BACKEND_URL pointed at live Cloud Run
       (anacorporation-erp-backend-….run.app) while Nest local was on 3002.
       Live still has SET active → UI kept showing SET.

  2) Stale list rows in the browser
       Item Master uses useInfiniteList (in-memory rows), not a Redux items
       slice. Redux persists auth/IAM only (localStorage).
       After BE data changes OUTSIDE the FE delete flow (scripts), the open
       list / SPA session keeps the PREVIOUS pages until reset/refetch.
       Same effect if FE was loaded against live, then .env switched to local
       without a full FE restart — old rows stay on screen.

  3) Auto-refresh is OFF
       Lists do not poll. Soft-delete done by BE script does not fire
       requestDataRefresh() on FE. User must Refresh / remount.
