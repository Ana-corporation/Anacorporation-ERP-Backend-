1. APIs
--------------------------------------------------------------------------------

  List / Get / Create / Patch / Delete
    (existing)

  PUT /api/v1/companies/:companyId/roles/:roleId/permissions
    Body:
    {
      "permissionCodes": ["vendors:view", "vendors:create", "branches:view"]
    }
    - Works for system + custom roles
    - Empty array [] clears all permissions
    - Unknown codes → 400 with list of missing codes
    - Invalidates user-context cache for users on that role

  POST /api/v1/companies/:companyId/roles/:roleId/clone
    Body:
    {
      "roleCode": "FACTORY_STAFF",
      "roleName": "Factory Staff",
      "description": "optional"
    }
    - Copies all permissions from source
    - New role isSystem = false
    - Requires unique roleCode


2. RULES
--------------------------------------------------------------------------------

  System roles (isSystem=true): ADMIN, MANAGER, STAFF, SALES, VENDOR,
  INVENTORY_ADMIN, PLATFORM_OWNER (platform co.)

    Delete:  blocked
    Rename:  blocked
    Edit permissions: allowed
    Clone:   allowed (clone is custom / isSystem=false)

  Custom roles:

    Create / Rename / Delete / Clone / Edit permissions: allowed
    Create does NOT auto-assign permissions
