================================================================================
1) FILE APIs
================================================================================

  Auth: JWT + company scope
  Perms:
    POST / DELETE  →  vendors:edit
    GET url        →  vendors:view

  Max 10 MB each.
  Allow: pdf, doc, docx, xls, xlsx, csv, jpg, jpeg, png, webp
  Fields: `files` (repeatable) and/or `file` (same as items)


  POST   /companies/{companyId}/vendors/{vendorId}/attachments
         multipart/form-data

    200 envelope.data:
    {
      "attachments": [
        {
          "fileAssetId": "uuid",
          "fileName": "quote.pdf",
          "mimeType": "application/pdf",
          "fileSize": 1200,
          "storageKey": "...",
          "publicUrl": "..." | null,
          "attachmentDate": "YYYY-MM-DD",
          "status": "uploaded"
        }
      ]
    }


  DELETE /companies/{companyId}/vendors/{vendorId}/attachments/{fileAssetId}
         200  { success: true, message: "Attachment deleted", data: null }


  GET    /companies/{companyId}/vendors/{vendorId}/attachments/{fileAssetId}/url
         200 envelope.data: { "url": "<signed>" }

2) VENDOR CREATE / PATCH (UNCHANGED FIELDS)
================================================================================

  POST  /companies/{companyId}/vendors
  PATCH /companies/{companyId}/vendors/{vendorId}
  GET   /companies/{companyId}/vendors/{vendorId}

  Continue sending attachment *metadata* in:

    metadata.attachments: [
      {
        fileName, fileSize, mimeType, attachmentDate,
        fileAssetId, publicUrl, storageKey, targetPath,
        status: "uploaded" | "ready" | "failed"
      }
    ]

  BE:
    [x] Persists metadata.attachments (JSONB)
    [x] Does not strip unknown metadata keys
    [x] Echoes on GET vendor and GET list as:
          attachments
          attachmentsJson
          metadata.attachments
        (same array)

  Optional alias also accepted on POST/PATCH:

    { "attachments": [ ...same objects... ] }

  Top-level attachments is merged into metadata.attachments.
