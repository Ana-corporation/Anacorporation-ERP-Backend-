4. 401 / 403 CONTRACT (Q8–Q9)
--------------------------------------------------------------------------------

Q8. Error shape — CONFIRMED (GlobalExceptionFilter):

  {
    "success": false,
    "message": "Insufficient permissions",   // or Unauthorized message
    "data": null,
    "errors": [ ... ],                       // optional
    "timestamp": "...",
    "path": "..."
  }

  Permission guard message: "Insufficient permissions" (HTTP 403).

Q9. 401 vs 403 — CONFIRMED

  401 Unauthorized
    → missing / invalid / expired token (or session invalid)

  403 Forbidden
    → valid token + session, but role lacks required permission code
