Backend:  supplierType saved on Vendor + auto vendorCode (RM001 style)

1. SUPPLIER TYPE IS NOW IN DB + API RESPONSE
--------------------------------------------------------------------------------

  Prisma field:  supplierType  (vendors.supplier_type)
  Returned on:   GET list, GET one, POST create response

  Exact values (dropdown):
    RM Supplier
    Component Supplier
    Service Provider
    Electrical Suppliers


2. CREATE FORM
--------------------------------------------------------------------------------

  Required:
    - supplierType  (dropdown, exact strings above)
    - name

  Do NOT send / do NOT let user type:
    - code / vendorCode   → auto-generated by backend

  POST /api/v1/companies/:companyId/vendors
  {
    "supplierType": "RM Supplier",
    "name": "CSK Metal Crafts"
  }

  Response includes:
    vendorCode: "RM001"
    supplierType: "RM Supplier"
    name: "CSK Metal Crafts"
    …


3. LIST / DETAIL — SHOW BOTH
--------------------------------------------------------------------------------

  Show:
    - vendorCode     e.g. RM001
    - supplierType   e.g. RM Supplier
    - name

  Filter (optional):
    GET .../vendors?supplierType=RM%20Supplier

  Sort (optional):
    ?sortBy=supplierType


4. EDIT (PATCH)
--------------------------------------------------------------------------------

  supplierType is NOT editable after create (tied to vendorCode prefix).
  Do not send supplierType on PATCH.


5. CODE RULES
--------------------------------------------------------------------------------

  RM Supplier            → RM001, RM002, …
  Component Supplier     → CS001, CS002, …
  Service Provider       → SP001, SP002, …
  Electrical Suppliers   → ES001, ES002, …

  No short-name suffix (not "RM001 CSKMETA").
