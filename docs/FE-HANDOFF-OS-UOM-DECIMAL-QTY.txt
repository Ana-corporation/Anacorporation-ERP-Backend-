================================================================================
FE NOTE — Opening Stock qty decimals
Date:       2026-11-24 (updated)
BE status:  Opening Stock no longer rejects qty by UoM decimal precision.
================================================================================

BE CHANGE
--------------------------------------------------------------------------------
  PUT/POST Opening Stock does NOT return INVENTORY_UOM_DECIMAL_PRECISION.
  Decimal qty (e.g. 1.5 on NOS) is accepted (max 6 dp on the column).

  Still enforced:
    - Serial-managed items → qty must be 1
    - lines[].uomDecimalPlaces is still returned (hint for UI)


FE (optional UX)
--------------------------------------------------------------------------------
  You may still limit input by uomDecimalPlaces for cleaner counts
  (NOS → whole numbers), but it is not required for save to succeed.


QUICK TEST
--------------------------------------------------------------------------------
  NOS item, qty 1.5  → save OK
  Serial item, qty 2 → still blocked (SERIAL_QTY_MUST_BE_ONE)

================================================================================
