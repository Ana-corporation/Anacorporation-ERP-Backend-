     Permission: form_configurations:view / form_configurations:edit

     Response shape:
     {
       "entityType": "vendor",
       "sections": [
         {
           "sectionKey": "general",
           "label": "General",
           "fields": [
             {
               "fieldKey": "vendorName",
               "label": "Name",
               "sectionKey": "general",
               "fieldType": "text",
               "apiKey": "name",
               "visible": true,
               "required": true,
               "configurable": false,
               "source": "BUILT_IN",
               "hasOverride": false
             }
           ]
         }
       ]
     }

     Rules:
     - Render EVERY sections[].fields row (including visible:false).
     - configurable:false → toggle locked On.
     - Do NOT invent fieldKeys. Do NOT hardcode Payment Terms list.
     - Custom fields are NOT in this response.

  B) Vendor create / edit form (merged schema — REQUIRED for Ana model)

     GET /companies/28/entities/vendor/form-schema

     Permission: supply-chain module view

     Prefer:
       resolvedSections[]   — BUILT_IN (visible only) + CUSTOM
       builtInFields[]      — all built-ins with visible flag
       fields[]             — legacy custom-only (still present)
       sections[]           — section tab metadata

     FE MUST:
     - Prefer resolvedSections for rendering Vendor form
     - Render field if visible === true (built-in) OR source === "CUSTOM"
     - For CUSTOM: bind value to customFields.<fieldName>
     - For BUILT_IN: bind via apiKey (name, email, metadata.x, taxId, …)
     - Use fieldType for control (text, phone, email, number, select, …)
     - PhoneInput for phone-like keys / fieldType phone
