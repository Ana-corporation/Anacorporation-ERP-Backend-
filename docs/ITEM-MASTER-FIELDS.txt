ITEM (MATERIAL) MASTER - CURRENT FIELDS
=======================================
Date   : 2026-11-03 (checked in code)
Tables : items, item_warehouse_stock, item_groups, uoms, store_categories,
         company_item_settings, number_series_* (part numbers)
API    : /api/v1/companies/{companyId}/items
Screen : Item Master (SAP Business One style tabs)
Perms  : items:view | items:create | items:edit | items:delete

Legend:  * = mandatory   [col] = real DB column   [json:x] = stored in the
         x_json bag (open key/value, not a column)   [lock] = cannot change
         after create


1. HEADER (top of the form)
---------------------------
  Field            Store     Type / size        Notes
  itemCode *       [col]     text 50  [lock]    Part number. Unique per company.
                                                AUTO / MANUAL / Number Series
                                                (see section 9). Never renamed.
  description *    [col]     text 255           Part name, e.g. "MAIN SIDE PLATE RH"
  itemType         [col]     item | service | labor | travel   (default item)
  isInventoryItem  [col]     yes/no (default yes)
  isSalesItem      [col]     yes/no (default yes)
  isPurchaseItem   [col]     yes/no (default yes)
  storeCategoryId  [col]     -> store_categories  [lock]
                                                Raw Material / Spares / Bought-Out
                                                / Electrical ... Required when the
                                                ITEM number series is active.
  itemGroupId      [col]     -> item_groups     Category (BRG, FST, PLY ...).
                                                Must belong to the item's store.
  inventoryUomId   [col]     -> uoms            NOS, KG, MTR ... (also copied to
                                                inventory.uomName for stock screens)
  image            [col]     file reference     PNG / JPG / WEBP, max 5 MB
                                                (POST /items/{id}/image)

-----------------------------------------------

9. ITEM CODE / PART NUMBER RULES
--------------------------------
  Company setting (company_item_settings):
    itemCodeMode   AUTO (default) | MANUAL
    itemCodePrefix default "ITM"  -> AUTO codes ITM00001 ...
  When the ITEM Number Series is active it wins over AUTO/MANUAL:
    part number = prefix + segment + serial, e.g. ANA + BO + 00001
    segment comes from the Store (store_categories.number_series_code)
    or the Category (item_groups.category_code), per the series setting.
  itemCode and storeCategoryId cannot be changed after create.
  Duplicate description in the same store -> warning; send
  confirmDuplicateName = true to save anyway.


10. MASTERS USED BY THE ITEM
----------------------------
  store_categories : name, codePrefix (RMS, SPR ...), numberSeriesCode
                     (hidden on screen now), description, sortOrder, isActive
  item_groups      : tree per store; name, categoryCode (2-4 letters, e.g.
                     BRG), description, parent, sortOrder, isActive
  uoms             : code (uppercase, unique), name, isActive
  vendors          : preferred vendor


11. SYSTEM FIELDS (every item)
------------------------------
  itemId, companyId, isActive, createdBy/At, updatedBy/At, deletedBy/At
  (soft delete), rowVersion


12. FIT CHECK - BS 500 BOM EXCEL (BS5000000000A1)
-------------------------------------------------
  Excel column      -> Item master field
  PART NUMBER       -> itemCode (MANUAL, or keep as oldCode)
  DESCRIPTION       -> description
  PART NAME group   -> itemGroupId (BEARING=BRG, ALLEN BOLT/HEX NUT=FST ...)
  PROCESS           -> storeCategoryId / itemGroupId
                       (RM-SF-FF = made in-house, FST, BRG, PLY, CMP ...)
  QTY / ITEM NO.    -> NOT an item field. Belongs to a BOM (parent, child,
                       qty, level) which does not exist yet.
  ASSY rows         -> item with itemType item + production.bomType label;
                       the child list needs a BOM table.

  Gap: there is no BOM / bill-of-materials table. Items can be loaded today;
  the BS 500 structure (which part, how many, under which assembly) cannot.

14. NOTES
---------
  - Most SAP-style fields (division, coreActivity, factors, customs, planning,
    production) are optional and unused by ANA today. Hide them per company
    with Form Configuration instead of deleting columns.
  - Tab bags (purchase / sales / inventory / planning / production) accept any
    key; they are not validated or reportable like columns. Promote a key to a
    real column only when it must be filtered, totalled or validated.
  - Material Inward uses its own mi_* tables and does not update
    item_warehouse_stock yet.
