Rules

Reference

Status & flow

Status chips used on every screen.

PO status

Draft→Pending approval→Approved→Sent→Partially received→Fully received→Closed

Side paths: Pending → Rejected → Draft (edit, resubmit). Pending → Withdraw → Draft. Any open → Cancelled (no new GRN). Approved → Amend → v2 Pending.

Send status (separate)

Not sent→Queued→Sent / Failed

Purchase Requirement status

Draft→Pending review→Approved→Partially converted→Fully converted

Any open → Cancelled. Open qty = required − qty on POs; never put on two POs.

Flow

Machine + BOM + qty → S3 check stock → PR (S2) → PO draft (S6) → approve (S7) → issue (PDF + email, S9) → GRN (S8) → stock IN → PO status
