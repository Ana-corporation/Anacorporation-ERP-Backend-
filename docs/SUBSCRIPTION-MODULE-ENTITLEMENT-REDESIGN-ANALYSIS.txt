CURRENT RUNTIME ENTITLEMENT LOGIC (AUTH PATH)
--------------------------------------------------------------------------------

  Source: CompanyAccessContextService.resolveEntitledModuleIds()

  1. Requires LIVE subscription (active or trial, not expired) → planId
  2. Loads plan_modules (only for isCustom comparison)
  3. Entitled modules = ACTIVE company_modules rows ONLY
     → plan modules alone do NOT grant access
  4. Intersects with primary role permissions + user_module_access
  5. Filters lifecycle to AVAILABLE / DEPRECATED

  THIS DIFFERS from target formula AND from docs/PHASE-1-AUTH-DECISIONS.txt:

    entitled = (plan_set UNION company_on) MINUS company_off

  Platform company summary (companies.repository.ts) is closer to
  plan ∪ company_modules. Login/auth path is NOT.
