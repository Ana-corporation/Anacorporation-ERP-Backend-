================================================================================
TEMP PASSWORD TTL — BACKEND IMPLEMENTED
Date:       2026-08-07
Config:     TEMP_PASSWORD_TTL_HOURS (default 24, minimum 1)
================================================================================


1. INVITE (new user)
--------------------------------------------------------------------------------

  Sets on user_authentication:
    mustChangePassword = true
    passwordExpiresDate = now + TEMP_PASSWORD_TTL_HOURS
    lastPasswordReset = now


2. LOGIN
--------------------------------------------------------------------------------

  After password hash matches, if:
    mustChangePassword=true AND passwordExpiresDate < now

  → 401
  {
    "success": false,
    "message": "Temporary password has expired. Ask your admin to invite again.",
    "code": "TEMP_PASSWORD_EXPIRED"
  }

  Login history failureReason = "Temporary password expired"


3. CHANGE PASSWORD
--------------------------------------------------------------------------------

  On success:
    mustChangePassword = false
    passwordExpiresDate = null
    passwordChangedDate = now


4. CONFIG
--------------------------------------------------------------------------------

  .env:
    TEMP_PASSWORD_TTL_HOURS=24

  Missing → 24
  < 1 → rejected by env validation (or clamped to 1 in runtime config)
