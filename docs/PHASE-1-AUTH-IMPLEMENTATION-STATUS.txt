SAAS MODEL (IMPORTANT — READ FIRST)
================================================================================

  YOUR PRODUCT (company customer):
    Person signs up -> becomes COMPANY ADMIN (tenant admin) for their company.
    Table path: users + user_companies + user_roles (role ADMIN)
    Login: POST /api/v1/auth/login { employeeCode, password, companyId|companyCode }
    Manages: their company only (users, roles, modules, org setup)

  PLATFORM ADMIN (optional — Ana Corporation internal team):
    Table: super_admins (separate from company users)
    Login: POST /api/v1/super-admins/auth/login { email, password }
    Manages: platform super admin accounts only (not customer ERP data yet)
