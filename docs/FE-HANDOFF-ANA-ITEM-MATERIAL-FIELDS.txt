--------------------------------------------------------------------------------
  fieldName          displayName        type      required  options (value = label)
  materialCategory   Material Category  dropdown  yes       Mechanical | Electrical
  materialType       Material Type      dropdown  yes       Raw Material |
                                                            Semi-Finished |
                                                            Finished Good
  procurementType    Procurement Type   dropdown  yes       Buy | Make | Subcontract

  sortOrder 101 / 102 / 103. searchable, filterable, sortable = true.
  sectionKey "general" → itemTabForSectionKey() puts them on the General tab.

  Comes from GET /entities/item/form-schema (resolvedSections → general → fields with
  source CUSTOM). No hard-coding: render from schema like other custom fields.

  SAVE (POST / PATCH /items):
    {
      ...,
      "customFields": {
        "materialCategory": "Mechanical",
        "materialType": "Semi-Finished",
        "procurementType": "Subcontract"
      }
    }
  Send the option VALUE (same text as the label).

  REQUIRED RULE
    Create: all 3 must be sent, else 400 "Custom field "Material Type" is
    required" (errors[].field = customFields.materialType).
    Update: omitting customFields leaves values as they are. Sending a key
    with "" or null → 400 required.
